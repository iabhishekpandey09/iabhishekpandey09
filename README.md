# 🚀 Featured Projects

## 📚 BookReview
A full-stack book review platform where users can browse books, create custom shelves, and write, update, or delete reviews.

**Tech Stack:** Node.js, Express.js, MongoDB, JWT, React  
**Highlights:**
- Built secure backend APIs for books, shelves, and reviews
- Implemented Google OAuth and JWT-based authentication
- Designed MongoDB/Mongoose schemas for scalable data handling
- Integrated React frontend with Express APIs for smooth UI flows

## 👶 Vatsalya – Maternal & Vaccination Reminder System
A healthcare-focused platform that generates vaccination schedules and sends timely reminders for pregnancy and child immunization.

**Tech Stack:** Node.js, Express.js, MongoDB, EJS, JWT, Nodemailer, node-cron  
**Highlights:**
- Automated vaccination schedules based on India’s immunization program
- Added role-based access for Mother, Family, Doctor, and Admin
- Sent daily reminder emails for upcoming vaccinations
- Built a responsive dashboard with one-click vaccination status updates
